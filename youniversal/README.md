# Youniversal theme library

`dev.youniversal.theme` — the reusable half of this repository. Full documentation lives in the
[root README](../README.md); this file covers what you need to consume the module.

**Coordinates:** `dev.youniversal:youniversal-theme:1.0.0`
**License:** MIT
**`minSdk`:** 24 · **`compileSdk`:** 36 · **Kotlin:** 2.3.20 · **Compose BOM:** 2026.04.01 (Material 3 1.4.0)

## Add it

```kotlin
// settings.gradle.kts
include(":youniversal")
```

```kotlin
// app/build.gradle.kts
dependencies {
    implementation(project(":youniversal"))
}
```

The module brings in the Compose BOM, Material 3, `ui`, `ui-graphics` and `foundation` as `api`
dependencies, so you get them transitively. It has **no** dependency on `material-icons-*`;
components that show an icon take an `ImageVector`.

## Use it

```kotlin
val theme = rememberYouniversalThemeState()

YouniversalTheme(state = theme) {
    YouniversalScaffold(
        topBar = { YouniversalTopBar(title = "Home") },
        bottomBar = { /* YouniversalBottomBar { … } */ },
    ) { padding ->
        // MaterialTheme.colorScheme / typography / shapes are all Youniversal's now
    }
}
```

Or drive it imperatively, without persisted state:

```kotlin
YouniversalTheme(
    backgroundStyle = YouniversalBackgroundStyle.Cream,
    contrast = YouniversalContrast.High,
    cornerScale = 1.25f,
) {
    App()
}
```

## What it provides

| Area | Entry points |
| --- | --- |
| Theme | `YouniversalTheme` (two overloads: settings object, or call-site arguments) |
| State | `YouniversalThemeState`, `rememberYouniversalThemeState()` |
| Backgrounds | `YouniversalBackgroundStyle.Auto` / `Light` / `Dark` / `Cream` |
| Contrast | `YouniversalContrast.Default` / `High` |
| Schemes | `youniversalLightColorScheme()`, `youniversalDarkColorScheme()`, `youniversalCreamColorScheme()`, `youniversalColorScheme(style)` |
| Palette maths | `YouniversalTonalPalette.tone(seed, tone, chromaScale, hueShiftDegrees)`, `.colorScheme(seed, isDark)` |
| Colour helpers | `Color.youniversalLighten/Darken/At`, `youniversalRelativeLuminance()`, `youniversalReadableContentColor()`, `youniversalContrastAgainst()` |
| Scheme transforms | `ColorScheme.youniversalHighContrast(isDark)`, `ColorScheme.withCreamNeutrals(cream)` |
| Tokens | `YouniversalMetrics`, `youniversalShapes(cornerScale)`, `youniversalTypography(fontFamily, fontScale)`, `YouniversalMotion` |
| Extra roles | `YouniversalExtendedColors`, `YouniversalTheme.extendedColors` |
| Components | 45 composables — cards, buttons, inputs, chips, segmented controls, bars, FABs, dialogs, snackbars, list rows, avatars, badges, backdrops, empty states |
| Inspection | `youniversalColorRoles()`, `YouniversalColorSwatch`, `YouniversalPalettePreview` |
| Previews | `@YouniversalPreview` |

## Tests

```bash
./gradlew :youniversal:testDebugUnitTest
```

`YouniversalColorTest` runs on the JVM (the colour engine is pure Kotlin) and asserts the tone
generator's behaviour, WCAG AA for every shipped palette, AAA under high contrast, AA for
generated accent seeds, and that scheme transitions interpolate every role.

The palettes in `YouniversalPalette.kt` are generated by [`../tools/palette_lab.py`](../tools/palette_lab.py),
which independently reports the contrast of all 22 text/surface pairs in each scheme. Regenerate
rather than hand-editing hex values:

```bash
python3 tools/palette_lab.py
```
